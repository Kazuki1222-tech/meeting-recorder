# 会議レコーダー

Zoom / Teams の相手の音声と自分のマイクを、ブラウザだけで1本の音声ファイル（.webm）に録音するツール。サーバーには何も送らず、すべてPC内で処理する。

## 使い方

1. `index.html` を PC の Chrome か Edge で開く（GitHub Pages で公開したURLでも可）。
2. 「録音開始」を押すと画面共有の選択が出る。
   - ブラウザ版の Zoom / Teams → 「タブ」で会議タブを選び、「タブの音声も共有」を ON。
   - デスクトップアプリ（Windows）→ 「画面全体」を選び、「システム音声も共有」を ON。
   - デスクトップアプリ（Mac）→ 新しめの macOS / Chrome なら「画面全体」でシステム音声を選べる。出ない場合はブラウザ版で参加する。
3. 「停止して保存」→ 一覧からダウンロード。

オプションで「相手」「自分」を別ファイルでも保存できる。

## 注意

- 録音前に参加者の了承を取ること。
- ヘッドホン推奨（スピーカーだと相手の声がマイクにも入り二重になる）。
- スマホでは動かない（画面共有 API が使えないため）。
- HTTPS か `file://` で開くこと（HTTP だとマイクと画面共有が使えない）。
